# Aplicación Android

Cliente Kotlin que consume la API compartida con la web. La pantalla de la persona adulta mayor prioriza el próximo aviso, texto legible, controles grandes y pocos pasos. Los permisos de cuidador se muestran sólo a cuentas vinculadas y autorizadas.

No se guardarán credenciales administrativas de Supabase en la app. Las notificaciones Android complementan la programación del ESP32; no sustituyen su alarma local.
